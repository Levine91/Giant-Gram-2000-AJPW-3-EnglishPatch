# Giant Gram 2000 English v1.0

First English patch release by Levine91.

Attachment: **GG2000EnglishV1.dcp** (the maintainer-supplied file, unchanged).

Project work includes English menus, wrestler names, Create-A-Wrestler labels, move-list terminology, history-mode text, interviews, credits and tutorial text, plus layout corrections and manual ring-exit changes for singles/tag matches. Kongo helmet removal was reverted and is not a release feature.

Apply with [Universal Dreamcast Patcher](https://github.com/DerekPascarella/UniversalDreamcastPatcher) to your own compatible game image. Use a fresh boot rather than an old emulator save state when checking patched content.
